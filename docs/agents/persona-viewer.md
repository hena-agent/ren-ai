# Persona sessions in OpenCode

Open <https://oc.renai.im> and sign in with the existing OpenCode credentials. All active, retained and ended sessions of a persona open in `/srv/ren-ai/personas/<persona-id>/`; search by the User's Handle to find a Conversation. The root `/srv/ren-ai` is the read-only plugin/config location.

The native OpenCode interface is fully interactive. Prompts and controls act on the live session, and iMessages are sent through its conversation-bound `send`, `read`, `react`, and `wait` tools. The custom read-only viewer has been removed.

After `/reset`, a test handle's relationship is ended through the common Relationship ending flow. A Notification from `noti@renai.im` provides the private Reselection link; the test handle chooses another Persona through Discovery and is started from Admin's waitlist. The User, consent, registrations and earlier Conversations retain their history; the ended Relationship state and Relationship memory remain available for read-only review. Shared State, including language proficiency, and Life memory continue. Opening an old browser tab still opens that old session, but it cannot send or change State or Memory; only the current active binding can act on the Conversation.

Inspect `.opencode/agents/<persona-id>.md` for the persona agent, `AGENTS.md` for ground rules, `persona.json` for its catalog snapshot, and `opencode.json` for its default agent and disabled built-ins. Catalog and ground-rule updates refresh one root per persona, including the instructions seen by retained sessions. Persona versions preserve identity history. Editing generated files is not a Catalog update.

The root holds shared State and Life memory; `conversations/<conversation-key>/` holds each relationship's private documents. Tools expose only the shared scope and the calling session's own Relationship scope. Deleting or rebuilding an OpenCode session preserves both; replay cannot write State or Memory. Rebuild preserves its source session and admitted-history boundary durably across restarts, holds new input for the writable current session, and never reopens an ended relationship. A Relationship scope is removed only with its Conversation's data. Operator-created native sessions and forks run in separate Sandboxes on copies, while test-handle Conversations participate in the persona's shared life and five-current-Assignment limit.

Deployment, paused folder cutover, and independent host replacement are described in the [operations runbook](../../apps/api/ops/README.md); the Mac side is in the [Messages Mac runbook](../../apps/imsg/ops/README.md).
