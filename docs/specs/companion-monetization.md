# AI 컴패니언 과금 방향

## 결정

**무료 체험 후 지속적인 연락에 과금한다.** 연애 성사 여부는 결제 조건이 아니다. 사용자는 페르소나와 무료로 알아갈 수 있고, 무료 체험이 끝난 뒤 계속 대화하려면 구독한다. 썸·연애·거절 등 관계의 결과는 결제 여부에 따라 바뀌지 않는다.

## 제품 원칙

- 페르소나는 사용자가 알아가기를 확정할 때 전속 배정한다. 종료 후에는 기본적으로 다시 노출하지 않고, 어드민이 검토해 재등장을 허용할 수 있다.
- 무료 체험의 총량과 구독 가격은 선택 전에 알린다. 체험 한도 도달 시 앱/서비스가 안내하며, 페르소나가 결제를 요구하거나 결제 때문에 고백·이별하지 않는다.
- 무료 체험에는 사용자당 비용 상한을 둔다. 짧은 문자 여러 개가 하나의 대화로 이어질 수 있으므로, 한도 단위(메시지·대화 턴·기간)는 검증 후 결정한다.
- 결제 중단이나 한도 도달은 서비스 이용 상태로 처리한다. 응답할 수 없는 시간을 관계상의 무응답으로 계산하지 않는다.

## 검증할 것

무료 체험 한도와 재시작 정책, 구독 가격과 제공 범위, 사용자당 무료 대화 원가, 체험→구독 전환율, 결제 중단 시 페르소나의 상태와 재등장 기준.
