What does the model receive each turn?

Each model request the persona makes is rendered exactly as OpenCode would send it: the system prompt, the tools, and the message history (one prompt per iMessage message), plus a last line our context hook adds. Pick a scenario, then click a model request in the iMessage column, or use ← →. React to two things: the format, and which signals make the cut.

Assumptions: the tool set (send, react, wait) is a placeholder until The persona's iMessage actions settles it. Her replies are scripted, so turning a signal off changes what she sees, not what she does. OpenCode 2.0.16's own behaviour is reproduced where it matters: its compaction wrapper and its date and restart notices.
