# Mac mini operations

Run `ops/install.sh` as `chris` from the repo at `/Users/chris/git/hena-agent/ren-ai`. It creates owner-only XDG state/log/socket directories and installs two per-user LaunchAgent plists **without loading them**. Keep the desktop logged in and awake; turn off automatic macOS installs and turn on Messages' “Send read receipts.” The server only listens on `127.0.0.1:4700` (Cloudflare Tunnel for `api-msg.hena.dev`) and `127.0.0.1:4701` (Tailscale Serve HTTPS 8447). Do not expose either listener directly. Run `tailscale serve --bg --https=8447 http://127.0.0.1:4701` on the mini. The operator socket is `$HOME/.local/state/ren-ai/operator/operator.sock` (owner-only directory and socket).

Create login Keychain generic-password items with `/usr/bin/security add-generic-password -U -s dev.hena.ren-ai.<name> -a api-msg -w` (enter each value at the prompt), for `turnstile`, `viewer`, `discord`. The existing Go key is service `dev.hena.ren-ai.opencode-go`, account `personas`. Check the persona files in `~/git/hena-agent/persona` before starting. The approved Korean privacy copy and version `2026-09-28` live together in `packages/onboarding/src/locales/ko.json`, the **single source** for site and server. Before deploying a revision, review the complete Korean text, the unchanged service Notice, and the version there; if a future version is not approved, set it to `pending` to keep onboarding shut. The site deploys before the manually deployed API, so deploy a reviewed version on both sides before accepting its consent.

Provider facts checked September 28, 2026: [OpenCode Go's privacy table](https://opencode.ai/docs/go/#privacy) lists DeepSeek V4.1 Flash as not used for training and 0-day retention, but says its DeepSeek zero-data-retention agreement is renewed monthly and the **currently posted agreement ends September 30, 2026**. Do not assume renewal or extend that claim past its date without rechecking the primary page. [OpenCode's terms](https://opencode.ai/legal/terms-of-service) say OpenCode does not retain conversation Content but cannot control third-party model providers' retention. [DeepSeek's public policy](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html) excludes downstream apps from its coverage; do not infer the actual processing country of our Go route from that policy. The public copy makes no verified-country claim. These are publication facts, not changes to the accepted provider choice.

For **first start**, sit at the Mac and add `/Users/chris/.bun/bin/bun` to Full Disk Access and Accessibility, then load both plists with the commands printed by `install.sh`. Approve the Automation prompts for Messages and System Events **from the launchd-started Bun** immediately. A prompt left unanswered can become a hidden denial; `tccutil reset AppleEvents` and a fresh attended start are needed to recover. Confirm Discord alerts from the running server, disk and screen checks, the viewer behind its password/Tailscale, and a test Handle's Notice/Greeting only after privacy approval. Do not test with the maintainer's personal Conversations. There is no external offline monitor for the Korean testing period: if the Mac or server stops, Discord alerts from the server also stop.

Deploy from another machine with `ops/deploy.sh [tailscale-ssh-host]`. It fetches and fast-forwards `main`, installs pinned dependencies and restarts the per-user LaunchAgent. The daily rotation agent copy-truncates stdout/stderr and keeps 14 days under the state directory. Nightly snapshots of both persona databases live only in the owner-only `backups/` directory under the state directory; snapshots older than 14 days are deleted during nightly cleanup and failures raise Discord alerts. There is no paid third-party or offsite backup for this testing period: loss of the Mac or disk loses both live data and backups. Do not remove any existing backup files or the unused Keychain backup key as part of this change. From SSH, run `/Users/chris/.bun/bin/bun run packages/api-msg.hena.dev/src/operator-entry.ts remove|block|rebuild HANDLE` or `... remove-waitlist EMAIL` with `XDG_STATE_HOME=/Users/chris/.local/state/ren-ai`. Waitlist emails have no automatic expiry; remove them on request. User removal deletes service records and the OpenCode session, not the Apple Messages history.
