# Mac mini operations

Run `ops/install.sh` as `chris` from the repo at `/Users/chris/git/hena-agent/ren-ai`. It creates owner-only XDG state/log/socket directories and installs two per-user LaunchAgent plists **without loading them**. Keep the desktop logged in and awake; turn off automatic macOS installs and turn on Messages' “Send read receipts.” The server only listens on `127.0.0.1:4700` (Cloudflare Tunnel for `api-msg.hena.dev`) and `127.0.0.1:4701` (Tailscale Serve HTTPS 8447). Do not expose either listener directly. Run `tailscale serve --bg --https=8447 http://127.0.0.1:4701` on the mini. The operator socket is `$HOME/.local/state/ren-ai/operator/operator.sock` (owner-only directory and socket).

Create login Keychain generic-password items with `/usr/bin/security add-generic-password -U -s dev.hena.ren-ai.<name> -a api-msg -w` (enter each value at the prompt), for `turnstile`, `viewer`, `discord`, `r2-access-key-id`, `r2-secret-access-key`, `r2-endpoint`, `backup-key`. The existing Go key is service `dev.hena.ren-ai.opencode-go`, account `personas`. Check the R2 bucket name (`ren-ai`) in `src/server-entry.ts`, the R2 14-day lifecycle rule, and the persona files in `~/git/hena-agent/persona` before starting. The Korean privacy notice version is currently `pending`: onboarding intentionally sends nothing until legal copy is approved and the version is set in `server-entry.ts` to match the site's copy.

For **first start**, sit at the Mac and add `/Users/chris/.bun/bin/bun` to Full Disk Access and Accessibility, then load both plists with the commands printed by `install.sh`. Approve the Automation prompts for Messages and System Events **from the launchd-started Bun** immediately. A prompt left unanswered can become a hidden denial; `tccutil reset AppleEvents` and a fresh attended start are needed to recover. Confirm Discord alerts from the running server, disk and screen checks, the viewer behind its password/Tailscale, and a test Handle's Notice/Greeting only after privacy approval. Do not test with the maintainer's personal Conversations. There is no external offline monitor for the Korean testing period: if the Mac or server stops, Discord alerts from the server also stop.

Deploy from another machine with `ops/deploy.sh [tailscale-ssh-host]`. It fetches and fast-forwards `main`, installs pinned dependencies and restarts the per-user LaunchAgent. The daily rotation agent copy-truncates stdout/stderr and keeps 14 days under the state directory; backups live under `backups/`. From SSH, run `/Users/chris/.bun/bin/bun run packages/api-msg.hena.dev/src/operator-entry.ts remove|block|rebuild HANDLE` with `XDG_STATE_HOME=/Users/chris/.local/state/ren-ai`.
